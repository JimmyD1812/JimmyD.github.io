Publish to GitHub

One click commits both data files to your repo and starts the site rebuild. No downloading or uploading files.

No token yet? Create one at GitHub → New fine-grained token: name it DM Desk Publish, expiry ~90 days, Repository access → Only select repositories → JimmyD.github.io, Permissions → Contents: Read and write, Actions: Read and write. Generate it, copy it, paste it above, Save token. The token is stored only in this browser — it never goes in the repo or the exported files.
