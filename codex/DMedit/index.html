DM Desk

Not linked from the player site. Keep this address to yourself.

How saving works: edits are stored in this browser as you work. When you're ready to go live, save a GitHub token in the Publish box below (one time), then hit Publish to jimmyd.space — it commits both data files and starts the Rebuild website (no cards job) rebuild for you. The player data file only ever contains player-visible articles — DM-only and draft articles are written only to dm-data.js, which lives in this folder and is never loaded by the player page.

Calendars

Calendars publish to players with the world. Timeline events can then carry a calendar date, and the player Calendar page shows months, moons, and the current day.

Maps

Click the map to drop a marker. Drag a marker to move it; click one to edit it below.

Maps publish with the world; DM-only markers never reach the player file. Embed a map in an article body with [map:Map Name].

Categories

Deleting a category moves its articles into the first remaining category. Renaming is safe — articles follow automatically.

Statblocks

Use one inside an article body with [sb:Exact Name]. Player-visible statblocks also get their own tab on the player site.

Article templates

Templates travel in dm-data.js when you Publish, so both your devices share the set. "Save as template" in the article form captures an article's headings and structure only, never its words.

Snapshots & rollback

Full copies of everything in this Desk, kept in this browser under their own key, so they survive "Discard local edits" and never get published. One is taken automatically before each Publish and on the first open of each day. Restoring replaces what's in the Desk now, and a safety snapshot is taken first, so a rollback can itself be undone.

Pending images

None. Images you add wait here (in this browser) until you Publish.

One click: pending images upload first, then both data files, then the rebuild runs. Published images are public files — a DM-only article's image is protected only by its scrambled filename.

No token yet? Create a fine-grained token: this repo only, Contents + Actions read/write. Paste it above and Save — it's stored only in this browser.

Two or more headings in one article add an automatic Contents box above the first heading. [img:file] on its own line inserts an image; [sb:Name] inserts a statblock; [map:Map Name] embeds a map.

Inserted images appear in the text as [img:filename] and upload on Publish, along with the cover image.
